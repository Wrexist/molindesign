**Description** (paste it in full, because the PC can't read repo files). It contains no < or > characters (checked by script):

> This torn QR code still scans. So how does it read what's gone? Part of every QR code is backup. Denso Wave, the company that invented the QR code, says its error correction works by adding a Reed-Solomon code to the data, the same kind of math used for music CDs, so the code can "restore data if the code is dirty or damaged".
>
> How much? There are four levels. At the top level, H, about 30% of the codewords can be restored (L about 7%, M about 15%, Q about 25%). A codeword is 8 bits, so "bytes" is the plain word. That's 30% of the data, not 30% of the printed square, so don't rip a third off and expect a scan.
>
> But only if the three corner squares survive. Denso calls them position detection patterns: they tell the camera that a code is there and where it is, and with three of them it can tell which way is up from any angle. Masahiro Hara's team picked their 1:1:3:1:1 stripe pattern after searching fliers, magazines and cardboard boxes "all day long for days on end" for the ratio that almost never shows up in print. Denso Wave announced the QR code in 1994, for factory sites where codes get oily and dirty. And its maker says most codes carry less backup: "Typically, Level M (15%) is most frequently selected."
>
> So, find a QR code near you. Which corner is empty? One word in the comments.
>
> Fine print: the 30% and 15% are Denso Wave's approximate figures for codewords, from its outline of the ISO/IEC 18004 standard; how much paper you can lose depends on where the damage falls, because a tear's area doesn't map one-to-one to codewords. The code in the video is a real version 3, level H QR code that reads "TECH, EXPLAINED". We tested every on-screen scan with two open-source decoders, ZXing-cpp and zbar, on the rendered frames: the hook's tear covers about 10% of the code's modules and flips 11 of its 70 bytes, about half of what level H can fix, and stays clear of the corner squares, the format strips beside them and the timing lines. The corner tear really fails both decoders, and a smaller nick in a corner square still scanned, so "survive" means readable enough. It has not been tested with a phone camera. "Built in 1994" means Denso Wave announced it that year; development ran about a year and a half before. "Most frequently selected" is Denso Wave's statement about what users pick, not a count of codes in the wild. This is about the standard square QR code (Model 2); Micro QR codes have one corner square. The car-part tag, menu, parking sign and ticket are props drawn for the video, and no real scanner app is shown.
