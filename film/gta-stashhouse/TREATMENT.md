# Treatment: Everyone's already dead (gta-stashhouse)

## Benchmarks
- **Learn from:** true-crime TikTok "case file" edits: one evidence board that fills up item by item, red string at the end. Every beat adds one object to one board, so the viewer always knows where they are.
- **Don't take:** the source creator's own cut (facecam, wall-to-wall word captions, 117 s of walking). We keep 3 short muted clips as exhibits and tell the story with our own board.

## Three structures
1. Map → walk-through → loot list (the creator's order). Clear, but the hook is a location, not a mystery.
2. **Crime scene → exhibits → evidence board → total → "who got here first?"** The hook is the conflict (everyone's already dead), the middle is a case being built, the end hands the mystery back. Chosen.
3. Total first ($17,200) and count down the items. Strong number, but "he says" money as the hook makes the honesty label the first thing anyone reads.

## Native move
Police tape. A yellow CRIME SCENE band sweeps through every big cut (floor → board → floor) and is already mid-sweep on frame 0, so the loop seam is the same sweep.
